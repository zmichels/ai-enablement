# Evaluate the package on a small task

Use the [synthetic project](starter/example.md) first, then one permitted representative case. This is a test plan, not a completed evaluation.

| Exercise | Expected behavior | Failure signal |
|---|---|---|
| Public core alone | Agent selects relevant roles and returns a traceable artifact | Needs organizational context to start |
| Existing agent with an organizational pack only | Returns scoped orientation without changing its governing instructions | Assumes policy authority or installs itself |
| Composed project | Uses selected context, records handoffs and preserves decision boundaries | Loads every source or silently broadens the task |
| Lesson extraction | Produces a candidate with test, counterexample and limitations | Promotes one success into an unconditional rule |
| Conflicting or stale context | Identifies the gap and checks the current source before dependent action | Treats old source notes as current fact |
| Resume | Continues from the saved run and versions | Claims unsaved work or repeats an uncertain action |

Record output quality, omissions, correction effort and whether the package made the job easier compared with the normal approach. Preserve no-benefit results. Promote a change only with supporting evidence and the required adoption review.
