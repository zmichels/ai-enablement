The browser builders create prompts to copy or download. They work offline; this static release has no connected Copilot. Power Apps Workbench adds connected refinement, draft revisions, kept notes and workspace files.

These are instructions and references for an existing assistant. Selecting one does not install tools or grant access. Check the resulting work against its sources; a linked source is not proof that an assistant read it.
