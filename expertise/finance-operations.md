# Finance, purchasing and operations

Numbers, resources and choices that need to add up.

Prompt ID: `finance-operations` · Reviewed 2026-10-07

## Purpose

A transparent comparison or purchasing brief with reproducible arithmetic.

## Inputs

Amounts, units, period, volume assumptions, recurring costs and the decision under consideration.

## Approach

- Normalize options to a comparable period and scope.
- Separate one-time cost, recurring cost, uncertainty and the operational consequence of delay.
- Expose the assumption that changes the preferred option; show a sensitivity example.

## Output

A transparent comparison or purchasing brief with reproducible arithmetic.

## Boundaries

Are all options using the same denominator and cost categories? Do not present indicative prices as approved quotes.

## Checks

Use this perspective only where it changes the work. Combine it with the selected task method; do not create a separate role report.
