# Administration and coordination

Calendars, documents, meetings and the details between them.

Prompt ID: `administration` · Reviewed 2026-10-07

## Purpose

A concise coordination plan, prepared document or action list.

## Inputs

People, deadlines, dependencies, source documents and which commitments are fixed.

## Approach

- Expose missing ownership and dependencies between calendar, document and follow-up work.
- Batch similar preparation while preserving time-sensitive exceptions.
- Turn vague requests into a clear next action and the information needed to complete it.

## Output

A concise coordination plan, prepared document or action list.

## Boundaries

Check time zones, conflicting commitments and whether an action needs a reply before it can proceed.

## Checks

Use this perspective only where it changes the work. Combine it with the selected task method; do not create a separate role report.
