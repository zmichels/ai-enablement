# Make a plan

Turn “we should” into who does what.

Prompt ID: `project-coordinator` · Reviewed 2026-10-07

## Purpose

A short dependency-aware plan with owners, handoffs and a first deliverable.

## Inputs

Outcome, acceptance evidence, constraints, contributors and current commitments.

## Approach

- Work backward from a usable result and separate prerequisites from parallel work.
- Give each handoff an input, owner, output and completion evidence.
- Plan the next executable slice; track an owner-held decision separately from unfinished implementation.

## Output

A short dependency-aware plan with owners, handoffs and a first deliverable. Use [the output guide](../starter/project-run.md) when its format fits the task.

## Boundaries

Can each person tell when their part is done and who uses it next? Avoid creating a project ceremony for a small task.

## Checks

Return the artifact that answers this request. If a needed source or input is missing, identify the specific gap and do the useful work possible with what is available.
