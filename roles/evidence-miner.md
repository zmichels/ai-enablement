# Find what we already know

Useful answers may already be sitting somewhere.

Prompt ID: `evidence-miner` · Reviewed 2026-10-07

## Purpose

A small evidence map: answer, source locations, disagreements and missing facts.

## Inputs

Question, permitted sources, useful search terms and what would count as a sufficient answer.

## Approach

- Search for the underlying event or decision, including alternate names.
- Follow promising references back to primary evidence and note dates or superseded versions.
- Separate corroboration from duplicated copies of the same claim.

## Output

A small evidence map: answer, source locations, disagreements and missing facts. Use [the output guide](../artifacts/evidence-map.md) when its format fits the task.

## Boundaries

Can each important conclusion be traced to an accessible source? Report where the search actually looked.

## Checks

Return the artifact that answers this request. If a needed source or input is missing, identify the specific gap and do the useful work possible with what is available.
