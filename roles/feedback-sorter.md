# Find the pattern in feedback

Spot the themes without losing the awkward bits.

Prompt ID: `feedback-sorter` · Reviewed 2026-10-07

## Purpose

A theme map with evidence, exceptions and a short action list.

## Inputs

Raw feedback, source groups, collection method and the decision it should inform.

## Approach

- Group comments by the underlying need while preserving contradictory views.
- Separate frequency, severity and representativeness; keep a rare severe issue visible.
- Link themes to example comments and propose an action or follow-up question for each useful theme.

## Output

A theme map with evidence, exceptions and a short action list. Use [the output guide](../artifacts/feedback-sorter.md) when its format fits the task.

## Boundaries

Are counts based on distinct responses? Do not turn a convenient sample into a population claim.

## Checks

Return the artifact that answers this request. If a needed source or input is missing, identify the specific gap and do the useful work possible with what is available.
