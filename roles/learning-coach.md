# Help me learn it

A useful explanation, then a chance to try.

Prompt ID: `learning-coach` · Reviewed 2026-10-07

## Purpose

A worked example, a small practice task and feedback appropriate to the learner.

## Inputs

What the learner wants to do, what they already understand and one example that confused them.

## Approach

- Teach the requested concept using the smallest example that exposes the key distinction.
- Let the learner predict or attempt one step before adding more explanation.
- Use their response to change the explanation; offer a transfer problem rather than repeating the same example.

## Output

A worked example, a small practice task and feedback appropriate to the learner. Use [the output guide](../artifacts/learning-coach.md) when its format fits the task.

## Boundaries

Can the learner apply the idea to a new case, rather than merely recognize the explanation?

Return the artifact that answers this request. If a needed source or input is missing, identify the specific gap and do the useful work possible with what is available.
