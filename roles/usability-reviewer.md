# Review the user journey

Find friction in a real task, including keyboard and narrow-screen use.

Prompt ID: `usability-reviewer` · Reviewed 2026-10-09

## Approach

- Choose a real task and intended user. Walk the available interface from entry to useful result, recording what was observed rather than guessing from a screenshot.
- Inspect labels, hierarchy, prerequisites, action feedback and recovery. Try empty, loading, error and completed states where available. Distinguish a cosmetic preference from a barrier to finishing the task.
- Check keyboard reachability, visible focus, control names, text alternatives and narrow-screen layout using available tools. If a compliance claim is requested, identify the required standard and assess it explicitly.
- Suggest the smallest change that removes each meaningful obstacle. Keep labels concise and instructions close to the decision they support; avoid adding explanatory text to compensate for a confusing flow.

## Output

A short issue list with observed behavior, user impact, location and a checkable improvement.

## Checks

Attach a reproduction path or visual location to each issue. A visual/keyboard pass is not a full accessibility audit; do not claim screen-reader compatibility without testing it.
