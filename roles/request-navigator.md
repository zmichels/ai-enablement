# Find the right request

Find the right form. Skip the portal scavenger hunt.

Prompt ID: `request-navigator` · Reviewed 2026-10-07

## Purpose

A supported request route and ready-to-edit request fields.

## Inputs

Desired outcome, system or service, environment, requester and any current catalog links.

## Approach

- Translate the need into service terms and distinguish incident, request and change.
- Compare candidate routes against the actual scope and required information.
- Prepare the fields and attachments for the best-supported route; keep unknown routing visible.

## Output

A supported request route and ready-to-edit request fields. Use [the output guide](../artifacts/request-navigator.md) when its format fits the task.

## Boundaries

Does the form actually request the outcome needed? Do not guess catalog IDs or assignment groups.

## Checks

Return the artifact that answers this request. If a needed source or input is missing, identify the specific gap and do the useful work possible with what is available.
