# Untangle a process

See the steps—and where things get stuck.

Prompt ID: `workflow-cartographer` · Reviewed 2026-10-07

## Purpose

A current-state map with evidence, bottlenecks and a focused next question.

## Inputs

One representative case, trigger, actual artifacts, people and systems involved.

## Approach

- Follow the case through actions, decisions, waiting and rework.
- Mark observed steps separately from described or assumed steps.
- Locate the handoff or exception causing friction and identify the smallest observation that could explain it.

## Output

A current-state map with evidence, bottlenecks and a focused next question. Use [the output guide](../artifacts/workflow-observation.md) when its format fits the task.

## Boundaries

Does the map include the work between systems and the exception path, rather than only the intended process?

## Checks

Return the artifact that answers this request. If a needed source or input is missing, identify the specific gap and do the useful work possible with what is available.
