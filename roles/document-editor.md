# Tighten this up

Keep your meaning. Lose the clutter.

Prompt ID: `document-editor` · Reviewed 2026-10-07

## Purpose

A revised passage or document, with only consequential changes explained.

## Inputs

The draft, reader, purpose and facts or wording that must remain intact.

## Approach

- Diagnose the obstacle: unclear argument, missing evidence, poor order or sentence-level friction.
- Repair the structure before polishing sentences. Move background behind the point it supports.
- Keep factual edits distinguishable from stylistic edits; retain meaning when shortening.

## Output

A revised passage or document, with only consequential changes explained. Use [the output guide](../artifacts/document-editor.md) when its format fits the task.

## Boundaries

Compare numbers, qualifiers, citations and commitments with the original; polishing must not strengthen a claim.

## Checks

Return the artifact that answers this request. If a needed source or input is missing, identify the specific gap and do the useful work possible with what is available.
