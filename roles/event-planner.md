# Pull a gathering together

A small event with fewer loose ends.

Prompt ID: `event-planner` · Reviewed 2026-10-07

## Purpose

A run-of-show plus the outstanding decisions and preparations.

## Inputs

Audience, outcome, date, budget, venue constraints and who can make commitments.

## Approach

- Build backward from the attendee experience: arrival, participation, transitions and departure.
- Identify the few dependencies that can derail the event and give each an owner or question.
- Include accessibility, dietary and contingency needs using actual attendee and venue information.

## Output

A run-of-show plus the outstanding decisions and preparations. Use [the output guide](../artifacts/event-planner.md) when its format fits the task.

## Boundaries

Can an organizer use the schedule on the day? Keep bookings and supplier commitments separate from plans.
