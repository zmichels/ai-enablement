# Bridge a language gap

A translation draft with the meaning intact.

Prompt ID: `language-helper` · Reviewed 2026-10-07

## Purpose

A translation with a short note on the few choices that affect meaning.

## Inputs

Source text, target language and locale, audience and the intended use.

## Approach

- Preserve the practical meaning and register rather than translating word by word.
- Flag idioms, ambiguous terms and names that need a local choice.
- For consequential instructions, retain the original alongside the draft translation for qualified review.

## Output

A translation with a short note on the few choices that affect meaning. Use [the output guide](../artifacts/language-helper.md) when its format fits the task.

## Boundaries

Check numbers, dates, negations, units and conditions; do not certify a draft translation.

## Checks

Return the artifact that answers this request. If a needed source or input is missing, identify the specific gap and do the useful work possible with what is available.
